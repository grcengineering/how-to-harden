# SSPM source reconciliation: posture and third-party risk

Reviewed 2026-11-27. These are separate source labels. First-party evidence below supports the bounded customer control surface, not the degree of visibility or write access afforded by an SSPM vendor. No tenant was accessed, settings changed or vendor messages sent.

| Source label | HTH scope | First-party evidence | Verified pack and limitation |
|---|---|---|---|
| Cyera | Customer DSPM and connected sources, not Omni DLP, Agent Guardian, or deployment-specific API/MCP setup | [DSPM](https://www.cyera.com/platform/dspm), [integration directory](https://www.cyera.com/integrations), [DataPort and MCP](https://www.cyera.com/blog/cyera-mcp), [customer API reference](https://api.cyera.io/docs) | REST docs required sign-in. Manual connector ownership and source IAM review; no native pack |
| Black Kite | Hosted third-party risk portal and Bridge, not vendor security attestations or product-driven scanning | [Vendor role response](https://blackkite.com/wp-content/uploads/2021/04/CISOs-Investigate-TPRM-Black-Kite.pdf), [Bridge Activities and outreach](https://blackkite.com/blog/introducing-black-kite-bridge-to-reduce-supply-chain-risk), [publisher-linked Swagger](https://app.blackkitetech.com/apidocs/v2/swagger/index.html) | Public Swagger wrapper exposed no readable settings/credential contract. Manual approved-assignment review; no native pack |
| JupiterOne | Hosted account access, credentials and audit events, not integrations' source tenants | [Admin settings](https://docs.jupiterone.io/features/admin/admin-settings), [SAML](https://docs.jupiterone.io/features/admin/saml-sso), [API authentication](https://docs.jupiterone.io/api/authentication), [audit query](https://docs.jupiterone.io/api/integrations-operations/#retrieve-jupiterone-audit-events-via-api) | US GraphQL single-page read only. Does not retrieve actor or event payloads and does not verify the audit stream’s completeness |
| Aqua | Aqua Platform SaaS Edition, specifically hosted Wave/CSPM. Unqualified label does not establish self-managed Enterprise, image scanning, or Trivy coverage | [Vendor SaaS versus self-hosted](https://github.com/aquasecurity/deployments), [Aqua Developer Center](https://cloud.aquasec.com/developers), [exact cloud-account list](https://github.com/aquasecurity/saas-api-samples/blob/master/sample-python/helpers/aqua.py), [signing sample](https://github.com/aquasecurity/saas-api-samples/blob/master/sample-python/helpers/auth.py) | Read-only default Wave/CSPM URL, using vendor sample’s millisecond timestamp and signed GET path. Provider aggregates are credential-scoped; no evidence for other regional endpoints, roles, API-key inventory or remediation rights |

No Cyera or Black Kite pack is supplied from draft API specifications or vendor trust pages. The first-party partner documentation proves those API surfaces exist, not their customer security administration contracts.
