# SSPM document services: source and automation coverage

Reviewed 2026-11-27. These rows address customer-operated settings in the exact product, not the settings of the SSPM provider or claims about which SSPM writes to each application. Plan availability and live behavior were not verified with a customer tenant.

| Exact platform | First-party evidence | Pack boundary | Follow-up evidence |
|---|---|---|---|
| Syncplicity Enterprise | [API authorization](https://support.syncplicity.com/hc/en-us/articles/115002028926-Getting-Started-with-Syncplicity-APIs), [API app allowlisting](https://support.syncplicity.com/hc/en-us/articles/12058981887629-Application-Whitelisting-and-Scopes), [enterprise provisioning](https://support.syncplicity.com/hc/en-us/articles/204758924-Provisioning-using-APIs) | Explicit opt-in issues a short-lived credential and confirms the intended company only. The token is not printed or retained. | Test app allowlisting behavior and approved scopes in the correct region. Do not infer usable endpoints from public provisioning labels. |
| DocuWare Cloud | [Organization security](https://knowledgecenter.docuware.com/docs/orgnaization-security-settings), [OAuth/REST](https://developer.docuware.com/rest/documentation.html), [organization collection schema](https://developer.docuware.com/dotNet_API_Reference/PlatformServerClient/DocuWare.Platform.ServerClient.Organizations.html), [organization discovery](https://developer.docuware.com/URL_Integration/examples/ids.html) | Read the Cloud organization collection without retrieving document data. A visible organization does not attest to specific roles. | Verify console policy, effective document-profile permissions and audit coverage separately. |
| Document360 | [API key management](https://docs.document360.com/docs/api-keys), [v3 API onboarding](https://apidocs.document360.com/apidocs/making-your-first-request), [team auditing](https://docs.document360.com/docs/team-auditing), [specification tooling](https://docs.document360.com/docs/ci-cd-integration) | Read-only v3 evidence of one visible project, conditional on no other pages. | DocHub | [SAML domain verification](https://help.dochub.com/knowledge-base/account-settings/sso-single-sign-on), [organization roles](https://help.dochub.com/knowledge-base/organizations/organization-roles-and-permissions), [DNS provider](https://registry.terraform.io/providers/hashicorp/dns/3.2.0/docs/data-sources/dns_cname_record_set) | Conditional public CNAME match, no changes and no public DocHub tenant admin API verified. | Verify the vendor-accepted domain and login behavior separately. Do not use other airSlate products' endpoints. |
