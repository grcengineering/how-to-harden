# SSPM business administration platform scope

Reviewed 2026-11-27. These guides cover customer-operated settings, not proof that a named posture provider can write them.

| Exact row and guide scope | Evidence and automation | Limits |
|---|---|---|
| Microsoft Dynamics 365 → Dataverse-backed Dynamics 365 Online | [Dataverse audit config](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/auditing/configure), [organization schema](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/reference/entities/organization), [Power Platform role CLI](https://learn.microsoft.com/en-us/power-platform/developer/cli/reference/admin#pac-admin-list-roles) | Read selected environment flags and role definitions. Do not read records or audit logs, infer effective privileges, or claim Finance and Operations, Business Central, or on-premises. |
| Microsoft Power Platform → tenant governance | [Native CLI](https://learn.microsoft.com/en-us/power-platform/developer/cli/reference/admin#pac-admin-list), [environment visibility](https://learn.microsoft.com/en-us/troubleshoot/power-platform/dataverse/environment-app-access/troubleshoot-missing-environments), [DLP](https://learn.microsoft.com/en-us/power-platform/admin/prevent-data-loss?tabs=new), [tenant isolation](https://learn.microsoft.com/en-us/power-platform/guidance/adoption/data-protection) | Count only visible environments; check an expected environment ID. Connector enforcement, effective policy and tenant isolation are separate from both this pack and Copilot Studio settings. |
| Microsoft Defender → Defender for Office 365 | [Netskope's SSPM row links Microsoft 365](https://docs.netskope.com/en/saas-security-posture-management) and cites the CISA SCuBA Defender baseline; [CISA's Defender baseline targets Office 365](https://www.cisa.gov/sites/default/files/2023-12/Defender%20SCB_12.20.2023.pdf); [Microsoft's preset rule read](https://learn.microsoft.com/en-us/powershell/module/exchangepowershell/get-atpprotectionpolicyrule?view=exchange-ps) | Complements existing M365 hub alerting. Exact scoped preset evidence only; not Defender for Endpoint, Cloud, Identity, Cloud Apps or XDR. No recipient data emitted. |
| Google Ads | [Manager mandates](https://support.google.com/google-ads/answer/12865295?hl=en), [user access](https://developers.google.com/google-ads/api/docs/account-management/managing-users), [non-mutating v26 Search](https://developers.google.com/google-ads/api/reference/rpc/v26/GoogleAdsService/Search?transport=rest), [developer token transition](https://developers.google.com/google-ads/api/docs/api-policy/developer-token) | Report a single confirmed-user page without emails. Search uses HTTP POST without changing Ads data; use OAuth and the authorized Google Cloud project, not a deprecated developer token. Pending, linked/inherited access and manager mandates are separate evidence. |
