# Cognition source-first coverage refresh

Started 2026-11-05, before selecting new controls. This ledger supersedes the **scope** of the [October census](/research/cognition-sources/), whose Poke exclusion answered a narrower question about products created by Cognition. The requested scope is now **all current Cognition products and common controls**, including acquired products. Historical evidence in that census remains historical, not a claim of retrieval in this run.

**Validation declaration:** no tenants declared — Tier 0+1 only. No product login, enrollment, credential creation, integration connection or settings change is authorized. Documentation research, local fixtures and rendering do not earn `ai-validated`.

This is not evidence that the current schema contains no other settings interfaces.

Updates serves one bundle without a version picker/notification; operators retain the prior verified bundle for rollback. Browser text artifacts were retained locally; no portal was accessed.
