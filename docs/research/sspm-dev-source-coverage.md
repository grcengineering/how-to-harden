# SSPM product coverage: Bitwarden, Fastly, and Grafana Cloud

## Scope decisions (2026-11-27)

- **Bitwarden:** Bitwarden Password Manager, hosted Teams and Enterprise. The [plan comparison](https://bitwarden.com/help/password-manager-plans/) separates Enterprise policy/SSO eligibility from the Teams organization capabilities. Secrets Manager, the distinct [Terraform provider](https://bitwarden.com/en-gb/help/terraform-provider/) that administers it, and self-hosting are outside this guide. The [proof-of-concept security setup material](https://bitwarden.com/help/proof-of-concept/) provides customer-facing setup; the security whitepaper concerns architecture, not the setting's exact navigation.
- **Fastly:** Fastly control panel account and organization settings. Fastly's [compliance page](https://www.fastly.com/compliance) describes assurance and availability of reports to customers; it does not prescribe 2FA configuration. The [linked-vs-unlinked distinction](https://www.fastly.com/documentation/guides/next-gen-waf/account-info/enabling-and-disabling-two-factor-authentication/) matters: unlinked Signal Sciences documents per-user 2FA without enforcement. Service cache, origin TLS, WAF policy, and users of the older service-specific account model need separate coverage and validation.
- **Grafana:** The [Valence listing](https://www.valencesecurity.com/saas-application-security) names Grafana without an edition. This SaaS guide covers the [hosted Cloud Portal and stack access models](https://grafana.com/docs/grafana-cloud/platform/security-and-account-management/security-and-access/authentication-and-permissions/), not Grafana OSS or customer-deployed Enterprise. Grafana's Cloud-specific organization MFA documentation takes precedence over the general self-managed Grafana authentication overview for this scope. Audit export, SCIM, SAML rollout and data-source permissions remain expansion candidates. Trust-report contents are not settings evidence.
- **Terraform:** No duplicate guide. [Palo Alto's onboarding instructions](https://docs.paloaltonetworks.com/saas-security/sspm/onboard-saas-apps-supported-by-sspm/onboard-a-terraform-app-to-sspm) expressly target Terraform Cloud, using app.terraform.io, already covered by HTH's Terraform Cloud guide. This is not a standalone Terraform CLI hardening row.
- **Benchmarks:** No product-specific entry was identified in the [CIS public selection](https://resources.cisecurity.org/benchmarks); the [CISA SCuBA scope reference](https://www.cisa.gov/sites/default/files/publications/FINAL-CSSO_SCuBA_FAQ.pdf) is not a baseline for these products. A standalone DISA STIG and product-specific NIST/NSA/ACSC settings were not verified. NIST references in the guides are informative control-objective mappings, not recommendation conformance. No incident claims were needed to originate the controls.

## Automation and residual coverage

| Surface | Bitwarden Password Manager | Fastly | Grafana Cloud |
|---------|----------------------------|--------|---------------|
| API | Public REST policy list is paginated; verify from the correct US/EU endpoint. Collection, member and event endpoints documented; broader inventory left for expansion. | Customer GET and organization-tier console enforcement are distinct. Account auth flags do not attest organization settings. | Organization MFA GET/POST and region-qualified read/write Cloud Access Policy endpoints are documented. MFA and existing policy collectors are read-only; no writeback tool inferred from a read. Stack HTTP API is a different authority. |
| CLI | Official bw supports organization metadata. Collection pack does not read vault item contents. | Official fastly supports customer-account user listing. | Official gcx supports caller organization memberships, not a directory of other organization members with this command. |
| Terraform | First-party Secrets Manager provider is out of Password Manager scope; Password Manager policy handles not verified. | Vendor provider exists; account/org auth policy handle unverified in current sample. Service resources are not substitutes. | First-party grafana_cloud_access_policy, with a stack realm and metrics:read only. No equivalent data-source handle independently verified; use API for exact policy read-back. |
| SDK | No Password Manager SDK handle validated for these controls; Secrets Manager SDKs are a different product. | SDK clients for API/Compute are separate; exact handle coverage not tested. | Provider and CLI are not language SDKs; independent SDK operations not validated. |
| Native configuration | Hosted policies live in the admin plane; self-host deployment variables excluded. | Compute build configuration does not set these account controls; no native admin policy file verified. | Provisioning files for self-managed instances do not establish Cloud Portal MFA and are outside scope. |
| SIEM | Event logs support export; production collector/SIEM-specific delivery is not validated. | Separate event and request-log interfaces not validated for these controls. | Audit log export coverage and tenant eligibility not validated. |
