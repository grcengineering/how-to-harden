# SSPM communications platforms: source and automation coverage

Reviewed 2026-11-27. This covers customer-side hardening and asserts no SSPM vendor write coverage, production validation, or entitlement.

| Exact platform | First-party evidence | What the packs do | What remains manual |
|---|---|---|---|
| GoTo Meeting | [GoTo Meeting features](https://www.goto.com/meeting/features), [Meeting API](https://developer.goto.com/GoToMeetingV1/), [shared Admin account discovery](https://developer.goto.com/guides/GoToConnect/09_HOW_fetchAccountUsers/), [Entra integration](https://learn.microsoft.com/en-us/entra/identity/saas-apps/citrix-gotomeeting-tutorial) | Confirm account visibility through a GoTo Admin read shared with other GoTo products; arbitrary account keys do not select a remote host. | Organizer license/role assignment, IdP and direct login enforcement, passcode/lock behavior, recording distribution. |
| RingCentral RingEX | [RingEX administrator guide](https://assets.ringcentral.com/us/guide/ringex_admin_guide.pdf), [account REST](https://developers.ringcentral.com/guide/account), [extensions](https://github.com/ringcentral/ringcentral-api-docs/blob/main/docs/account/extensions.md), [RingEX Admin MCP](https://developers.ringcentral.com/mcp/servers/ringex-admin/) | Read one explicitly scoped page of User extensions; don't emit contact data; don't apply a RingCX control or operate a write-capable MCP. | SSO exceptions, non-user service extensions, verified audit reporting, actual user privileges. |
| Genesys Cloud CX | [Customer hardening guide](https://help.mypurecloud.com/wp-content/uploads/2026/02/Hardening-the-Genesys-Cloud-Environment-Customer-Guide.pdf), [authorization API](https://github.com/MyPureCloud/platform-client-sdk-python/blob/master/build/docs/AuthorizationApi.md), [vendor CLI](https://github.com/MyPureCloud/platform-client-sdk-cli) | Read a project-approved account's role definition evidence with REST or CLI. REST supports documented commercial regions only. | Exact token/profile tenant, assigned users and divisions, effective permissions, OAuth governance and policy enforcement. |
| Kustomer | [Authentication](https://help.kustomer.com/en_us/categories/authenticate-users-S15_8jB48), [agent access](https://help.kustomer.com/manage-kustomer-access-Sk9na9x_), [audit API](https://developer.kustomer.com/api/core-resources/query-events-associated-with-your-organization), [Kusty](https://developer.kustomer.com/docs/ai/kusty) | Read one filtered audit-log page from a tenant-bound API hostname; output counts and pagination indication only. | Verify IP policy against each legitimate access path instead of assuming it covers machine-user keys. The separate Kusty CLI is not required or installed by this guide. |
