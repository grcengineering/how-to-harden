# Source coverage: endpoint and browser management platforms

The SSPM list gives product leads, not evidence that a given provider directly writes tenant settings. There is no enterprise tenant, lab browser or live SIEM verification in this tranche.

| Product and boundary | Admitted configuration and verification | API, CLI and infrastructure limits |
|---|---|---|
| Acronis Cyber Protect Cloud Management Portal | Customer and partner 2FA and roles, API-client tenant scoping, administrative audit. Acronis's Cloud partner and administrator docs cleanly distinguish this control plane from Cyber Protect 15 on-premises. | Account Management REST v2 client read is documented and shipped; not an effective role, MFA or API-scope verifier. Terraform, GraphQL, direct role automation, SDK, CLI, and audit export schema remain unverified. |
| Automox cloud control plane | First-party global/organization roles, organization and global API keys, Worklet metadata and Windows script signing, and audit exports. The provider's [security best practices](https://docs.automox.com/product/Product_Documentation/Getting_Started/Security_Best_Practices_When_Setting_Up_Your_Environment.htm) identify adjacent identity controls. | REST policy read shipped; separate Audit Trail and Cloud Worklets contracts documented, not implemented here. Agent commands are not tenant CLI; PowerShell examples use REST. Terraform, GraphQL and first-party admin SDK/CLI remain unverified. |
| Island Enterprise Browser | Island's browser/session controls and first-party Splunk add-on are distinguishable from tenant or IdP restrictions. The Microsoft–Island gallery documents supported Entra SAML and provisions target user/group identities. The exact public Island policy editor navigation could not be verified. | Splunk search covers a dedicated operator-selected index. The vendor-authored [service declaration](https://www.applytosupply.digitalmarketplace.service.gov.uk/g-cloud/services/661596834169927) describes REST availability; no speculative public write/read routes or permissions are published. GraphQL, CLI, SDK, Terraform and exact policy API schema remain unverified. |
| Bitdefender GravityZone Cloud Control Center | Artifact uses Bitdefender without an edition. The guide explicitly scopes to the hosted GravityZone human access, role, service API key, and logging surface. Cloud mandatory 2FA does not prove coverage of a separately configured IdP. | Public Accounts JSON-RPC documents the read method. Separate service and personal key authentication is documented; service-key scopes depend on product availability. No endpoint tamper, on-premises, consumer, Terraform, CLI, SDK or GraphQL coverage claim. |

## Source admissions and evidence gaps

- The guides originate steps from public first-party configuration, developer or jointly documented integration procedures. The [CIS benchmark catalog](https://www.cisecurity.org/cis-benchmarks) establishes adjacent operating-system and infrastructure baselines but no verified product-specific prescription is mapped here. No product-specific STIG, SCuBA, NSA or ACSC instruction is asserted.
- The [Acronis Trust Center](https://www.acronis.com/en/trust-center/), [Automox Trust Center](https://help.automox.com/hc/en-us/articles/31579821092372-Requesting-Access-to-Security-Documents-at-Automox), and [Island Trust Center](https://trust.island.io/) are discovery leads, not configuration sources. No private trust-portal documents were accessed. Public vendor support and product docs, not vendor attestations, substantiate the guide settings. A public Bitdefender trust catalog with customer configuration instructions was not established.
- For Automox and GravityZone, the starter reads do not replace a complete inventory. The Bitdefender Cloud account packet can omit a personal-key issuer. Other missing or unknown evidence does not mean the tenant passes.
- No scripts use tenant-write API methods. GravityZone uses POST only to transport the vendor's read-only JSON-RPC method. Island SPL uses no presumed vendor default index or fields.

The [Valence connector catalog](https://www.valencesecurity.com/saas-application-security) spells the rows Automox, Island and BitDefender, without specifying the Bitdefender edition. GravityZone Cloud is the strictly documented scope of the authored guide, not a claim that Valence's connector supports every GravityZone module or on-premises path.
