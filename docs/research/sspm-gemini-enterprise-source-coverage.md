# Google Gemini Enterprise SSPM source coverage

Reviewed November 27, 2026. This coverage is for Google Cloud Gemini Enterprise (Discovery Engine app and connector administration). It is separate from Google Workspace Gemini controls, the public consumer Gemini app, and Gemini Enterprise Agent Platform/Vertex AI APIs.

| Plane | First-party evidence | Verified read surface | Limits |
| --- | --- | --- | --- |
| Project IAM | [App access and project precedence](https://docs.cloud.google.com/gemini/enterprise/docs/iam-policy-for-apps), [Google Cloud CLI](https://docs.cloud.google.com/sdk/gcloud/reference/projects/get-iam-policy) | Direct project IAM through `gcloud projects get-iam-policy`. | Folder and organization inheritance, custom roles, groups and condition outcomes require separate review. |
| Resource IAM | [Granular resource access](https://docs.cloud.google.com/gemini/enterprise/docs/iam-policy-for-apps-and-data-stores), [app v1](https://docs.cloud.google.com/gemini/enterprise/docs/reference/rest/v1/projects.locations.collections.engines/getIamPolicy), [store v1](https://docs.cloud.google.com/gemini/enterprise/docs/reference/rest/v1/projects.locations.collections.dataStores/getIamPolicy) | Direct app and individual data-store policies, requesting policy version 3. | Not effective access, project feature state, connector collection policy, upstream document permissions or group membership. |
| Connector data boundary | [Connector fundamentals](https://docs.cloud.google.com/gemini/enterprise/docs/connectors/introduction-to-connectors-and-data-stores), [identity provider guidance](https://docs.cloud.google.com/gemini/enterprise/docs/configure-identity-provider) | Manual review of allowed paths, identity and synthetic source authorization. | No single generic connector permission check proves all downstream, source or document-level behavior. |
| Observability | [Configuration](https://docs.cloud.google.com/gemini/enterprise/docs/manage-observability-settings), [engine v1alpha GET](https://docs.cloud.google.com/gemini/enterprise/docs/reference/rest/v1alpha/projects.locations.collections.engines/get), [usage logs](https://docs.cloud.google.com/gemini/enterprise/docs/set-up-usage-audit-logs), [Cloud Audit Logs](https://docs.cloud.google.com/gemini/enterprise/docs/audit-logging) | Core Assistant observability flags and a project-scoped usage activity sample. | No agent-level settings, content, PII, prompts, responses or claim of comprehensive log integrity. |

No tenant credentials were used, no live requests were sent, and no remote settings changed.
