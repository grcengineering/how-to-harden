{%- comment -%} Maturity mark — THE single source of every status icon on the site. The ladder is a matrix, not a line: three STAGES (drafted → reviewed → validated) each done by either AGENT (ai = artificial intelligence, ni = natural intelligence, i.e. a person), and the two are not exclusive. STAGE picks the glyph family; AGENT picks the specific glyph within it: drafted / reviewed — pencil / eye, shared by both agents, with a small four-point spark added top-right for `ai` only. No spark means a person did it. Colour is the other channel: AI paints in the LIGHTER shade, NI the DARKER shade, of the stage hue (caller's stylesheet). validated — the two agents get DIFFERENT, self-contained glyphs instead of a shared one plus a spark: `ai` renders Feather's own `check-circle` (circle and check drawn as one glyph, not built by wrapping a bare checkmark in a hand-drawn circle — that approach is what caused the off-centre-checkmark and sparkle-clash defects fixed earlier the same day). `ni` renders Feather's `award` (a ribbon/medal), reflecting that NI validation is a human's certification, not an act a spark could denote. Neither carries a spark: the glyph itself is the agent signal at this stage, so a second one would be redundant. (Changed 2026-08-21, per live screenshots showing the circle-drawn-around-a-bare-checkmark reading as a worse, hand-rolled copy of an icon Feather already ships.) GLYPH GEOMETRY. Every path below is Feather Icons' stock path data verified against the upstream source (github.com/feathericons/feather, `icons/*.svg`), drawn in its native 24x24 viewBox with no group transform — Feather's own glyphs are already centred on that grid. A prior version wrapped the drafted/reviewed glyphs in `translate(-1.2 2.6) scale(0.8)` to shrink them and make room for the spark; that shift put the checkmark visibly off-centre once it started rendering inside a circular badge (fixed 2026-08-20). The spark's own coordinates are authored against these UNTRANSFORMED glyphs, which is what keeps it attached at the glyph's actual top-right corner instead of floating disconnected above it.
