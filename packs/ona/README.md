# Ona packs

Download the complete directory. API scripts require `api/common.sh`; Terraform recipes require `terraform/versions.tf`. These recipes target the independently administered Ona organization and runner plane described in the [guide](https://howtoharden.com/guides/ona/) and [source reconciliation](https://howtoharden.com/research/ona-source-coverage/).

Inject credentials from a secret manager. API transport keeps bearer values out of command arguments, ignores curlrc, validates HTTPS API destinations, bounds requests/responses, and redacts failures. Tests replace curl with synthetic fixtures; the pack exposes no HTTP or loopback bypass. Pagination and nested reads are staged privately and stdout is published only for a fully completed result (exit 0 or a completed finding result at exit 1); transport/schema failures publish no partial evidence. Exported metadata can remain sensitive. Set `umask 077` before redirecting stdout to a reviewed destination outside this repository. See the helper's `ONA_OUTPUT` contract when using a new private evidence file; staging permissions do not protect a file the calling shell already created.

HTH_PROFILE_LEVEL accepts 1–4, defaults to 1, and must meet the individual pack minimum. Read-only audit and explicit write/dry-run behavior remain distinct. Review the individual entrypoint's contract and documented opt-in before any mutation. This refresh executed offline fixtures only. Historical August 2026 tenant results remain dated evidence for unchanged surfaces; badges were removed from API transports changed in this refresh because those transports have not been run against a live tenant.

Terraform is pinned to the published 0.5.1 provider, which offers Linux amd64/arm64 releases and requires Terraform 1.14 or later. Each numbered recipe is an independent module: combine it with `versions.tf`, rather than combining all recipes' example variables/resources. Provider state, plans, environment snapshots and integration objects can contain sensitive data. Local formatting/source checks and Linux CI schema validation do not constitute a plan, apply or tenant test.
